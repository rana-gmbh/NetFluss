## NetFluss for Windows — 2.7.2 Beta

NetFluss for Windows catches up with **NetFluss 2.7.2 for Mac**: everything that arrived on the Mac in 2.7, 2.7.1 and 2.7.2 is now on Windows too — automatic DNS by Wi-Fi network, a connection indicator next to your rates, per-node proxy statistics, a searchable Preferences window and a round of reliability and security work.

> **On a Mac?** Nothing changes for you. This release is for Windows only.

---

## What's new

### Automatic DNS by Wi-Fi network

Give a network a rule and NetFluss switches the resolver when you join it — your own DNS at home, something else on café Wi-Fi (**Preferences → DNS → Automatic DNS**).

- Rules match the network name and can be **pinned to one access point**, so a network that merely borrows your router's name does not trigger them.
- **Any other network** covers everything without a rule, wired connections included, so a public resolver never follows you home.
- **Hotel and café logins keep working**: NetFluss waits until you are really online before switching. It also stands aside while a VPN profile sets its own DNS.
- It needs the **NetFluss helper**, so a network change never brings up an administrator prompt.

### On the taskbar

- **Connection indicator** — a Wi-Fi or cable symbol beside the rates: green when connected, amber when connected without internet, red when not connected. It uses Windows' own internet check, so NetFluss sends nothing of its own unless you give it an address to check. All three colours are yours to choose.
- **Active resolver** — the name of the DNS profile in use, shown only while it is not the system default.
- **Two new VPN marks**, **Globe** and **Bars**, besides the dot and the shield; the mark has its own size (10–18 pt) and keeps your colour whether or not a tunnel is up.
- **Rate alignment** — Left, Right or Centered (**Preferences → Taskbar**). Left and Right keep the arrows from sliding sideways as the numbers change.
- **Two lines, tidied up** — upload and download now sit together in the middle of the taskbar instead of at its top and bottom edges, and the meter takes only the width it needs.
- The exit-country flag can be shown **only while a VPN is up**, and Narrator reads the meter.

### Updates like on the Mac

- **An update asks for you.** When the daily check finds a new version, a window shows its release notes with **Install Update**, **Remind Me Later** and **Skip This Version** — no more going to About or to GitHub. The update is already downloaded and verified in the background, so installing takes a moment and NetFluss restarts by itself.
- **Or let updates install themselves** — tick **Automatically download and install updates** in that window or in **Preferences → General**. NetFluss then installs a verified update while none of its windows is open and its VPN is not connected, restarts, and tells you what it updated to.

### Also new

- **Rename the built-in DNS profiles** — call Cloudflare "Home" or Quad9 "Work". The name follows into the popover, the taskbar and every rule; the servers stay fixed.
- **Per-node proxy statistics** for clients with the Clash API — sing-box, mihomo, Clash Verge and others (**Preferences → Statistics**). Every node is listed, so a metered subscription can be reconciled; traffic the controller cannot attribute is shown separately instead of lost.
- **Search settings** at the top of Preferences (**Ctrl+F**).
- **Start with Windows** is now first on the General page, and says so when Windows has switched NetFluss off in its Startup apps, with a button to go there.
- **A short welcome** on a new install.

### Reliability and security

- **Disconnect really disconnects.** Quitting, updating or signing out takes the VPN down first, and a tunnel left behind by a crash is cleaned up — including WireGuard tunnels, which Windows would otherwise bring back at every start.
- **Windows VPN connections are followed live.** One connected in Windows Settings shows up in NetFluss; one disconnected there is shown as off instead of being dialled again.
- **Imported WireGuard configs are checked.** `PreUp`, `PostUp`, `PreDown` and `PostDown` lines could run commands with administrator rights, so such a config is now refused and the message names the line to remove. Remove it and import the config again.
- **Statistics that cannot be read** are kept aside and restored from a daily backup, instead of being replaced by an empty history.
- **System commands can no longer hang NetFluss** — a DNS change or helper install that never finishes now gives up with a message.
- **M-Lab speed test measures upload again** ([#64](https://github.com/rana-gmbh/NetFluss/issues/64)). Upload could stay at 0 while download and latency worked; it now uses the M-Lab server's own count of what arrived.

### Updating from Beta 2

The installed Beta 2 offers this update by itself (**About → Install and Relaunch**). Because the helper belongs to each version, NetFluss then asks you to **update the helper** once — Windows asks for administrator approval. If a WireGuard profile that worked before is now refused, remove the line the message names and import it again.

### "Windows protected your PC"

This beta is **not yet code-signed with a trusted certificate**, so SmartScreen warns the first time you run the installer. Click **More info → Run anyway**.

If your PC has **Smart App Control** turned on, Windows blocks apps without a trusted signature completely and the beta will not start.

To check a download, compare it with `SHA256SUMS.txt` (`certutil -hashfile <file> SHA256`). That list is signed (`SHA256SUMS.txt.sig`) — the in-app updater checks the signature before installing anything.

## What's in it

- **Live rates where you want them** — on the taskbar next to the clock, in the notification area, or in a floating widget. One line, two lines, total, or the **Dashboard** styles with a ring gauge; optional connection, VPN, country and resolver marks.
- **The popover** — totals, your adapters (rename, reorder, hide), your network path from PC to router to internet, the **DNS switcher**, a **Wi-Fi** switcher, **Top Apps**, **Data Usage**, the **Traffic Timer**, your **router** and your **VPN**. Reorder or hide sections, pin it as a window, and resize it.
- **Bandwidth Statistics** — adapters, apps and proxy nodes, from the last hour to the last year, or any custom range.
- **Speed Test** — Cloudflare or M-Lab, with a history you can annotate.
- **Network Slice** — which app talks to which server, live.
- **Routers** — Fritz!Box, UniFi, OpenWRT and OPNsense, with credentials kept in Windows Credential Manager.
- **VPN client** — OpenVPN and WireGuard profiles (a file, a folder or a provider's zip), or Windows' own IKEv2 connections. Auto-reconnect, connect at launch and a DNS preset while connected.
- **English, German, Simplified and Traditional Chinese.**

### Optional extras

- **The NetFluss helper** (*Preferences → General*) — Windows only lets administrators see which app uses the network, so **Top Apps** and **Network Slice** need it. It also switches DNS without asking each time, runs automatic DNS, and runs OpenVPN and WireGuard connections. Installing it asks for administrator approval once.
- **OpenVPN Community** and **WireGuard for Windows** — for VPN profiles of those kinds.

## Updates

The installed version **keeps itself up to date**: it checks once a day, downloads and verifies a new version in the background, and asks whether to install it — or installs it by itself if you allow that. Nothing is installed unless its checksum matches the signed `SHA256SUMS.txt`. As a beta tester you get the next beta, and then the final release. The portable version is updated by hand.

---

## Good to know

- **Taskbar placement** — Windows has no official way for apps to put text on the taskbar, so this is best effort. If a Windows update moves things around, NetFluss falls back to the notification area; the floating widget always works.
- **Automatic DNS and Wi-Fi names** — Windows 11 shares the Wi-Fi network name only with apps that have location access; allow it under *Preferences → General → System access*.
- **VPN** — WireGuard and Windows IKEv2 connections have been tested end to end. OpenVPN has been tested up to the connection to the server; reports from real OpenVPN servers are especially welcome.
- **Uninstalling** — *Settings → Apps → NetFluss*. If you installed the helper, Windows asks for administrator approval to remove it too.
